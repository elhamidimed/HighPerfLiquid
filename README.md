# HighPerfLiquid

High-performance C++ API for Hyperliquid focused on ultra-low-latency order book monitoring and high-frequency trading. Designed for speed and determinism, this library provides efficient WebSocket market data ingestion, real-time order book reconstruction, and fast order execution primitives suitable for HFT and systematic trading strategies.

## Status

🚧 Work in progress

## Goals

- Deterministic latency
- Zero allocations on hot paths
- HFT-grade market data handling
